# Security

Catter is currently in testing. No independent security audit is claimed.

Use GitHub's **Security > Advisories > Report a vulnerability** option if private reporting is enabled. Otherwise, open an issue asking for a private contact channel without including sensitive details.

Never post Apple passwords, verification codes, session tokens, pairing records, signing keys, provisioning profiles or unredacted device logs.

Download packages only from this repository's Releases page. Check the published file hashes before installation. Release-specific security and compatibility information will be included with each release.
